# Rock Paper Scissors

✊ Rock Paper Scissors game built with JavaScript, featuring interactive gameplay, score tracking, and dynamic round results.

## Features

* Play against a computer opponent
* Random computer choices
* Real-time score tracking
* Round result feedback
* Winner detection
* Interactive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## What I Learned

* JavaScript conditionals and functions
* Event listeners and user interactions
* DOM manipulation
* Random number generation
* Application state management
* Game logic implementation

## Project Goal

This project was built as part of The Odin Project curriculum to practice JavaScript fundamentals by creating an interactive browser-based game.
